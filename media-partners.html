Golden Luck arrives on 31 December 2026

The studio’s next slot closes out the year: a 25-payline game with a multiplier feature and medium-high volatility.

Golden Luck is the next title on the Vegas Studio release calendar, with a published release date of 31 December 2026. It joins a catalogue of 19 games and follows a busy autumn that saw five releases between September and November.

The game runs on 25 paylines with a 95% RTP configuration, medium-high volatility and a 40% hit rate. The maximum win is listed at 5,000. Its headline feature is a multiplier, and it launches in English.

Operators can request the game sheet and launch assets now; media partners can use the approved artwork in the media kit below.

Careers

Using our material

  1. Credit the studio

    Caption images “Image: Vegas Studio” and name the game.

  2. Keep artwork intact

    No cropping into the logo, recolouring or added effects. Resize in proportion only.

  3. Quote specs as published

    Use figures from the game page. Casinos may run different RTP configurations, so say so where it matters.

  4. Mind the audience

    Our games are for adults. Coverage that features gameplay should carry an 18+ notice. Responsible gaming

  5. Check dates before print

    Release dates can move. The game pages always show the current date.

Media, answered

Something else? Talk to the studio.

01How do I request an interview?

Use the contact page and choose Press. Tell us the topic, your publication and your deadline.

02Can I use game screenshots?

Yes, for editorial coverage, using approved assets and following the brand guidelines. Credit them “Image: Vegas Studio”.

03Where do release dates come from?

From each game’s catalogue page. If a date changes, the game page is updated first.

04Can I get early access to a game for review?

Ask the press desk. Demo builds and preview access depend on the release schedule.

05Do you have higher-resolution art?

Yes. Request it through the press desk with the game name and intended use.

06Can I quote the figures in the fact sheet?

Figures marked “catalogue” can be quoted. Check with the press desk before using any marked “to confirm”.
